Plan details

Clear limits. Independent choices.

Start with the base ERP, add only the operations you use, and increase only the allowance that needs more room.

Base ERP — R450

Includes 2,000 customers, suppliers and inventory records; 2,000 invoices and quotes each per monthly window; 5,000 payment records and manual bookkeeping entries each; and 1,000 supplier orders.

Operations — R100 or R150

Deliveries, Fleet, Calendar, Asset Register, Jobs and Advanced Analytics are R100 each. Project Manager is R150 and includes Jobs.

Seats — R75

Each extra employee or administrator seat is separate. One read-only Professional slot is included and does not use an employee seat.

Created-per-month allowances

A creation uses the allowance once. Deleting the record later does not return it. During an active multi-month prepaid term, allowance resets at each monthly usage window and does not roll over.

Currently-stored limits

These measure eligible records that exist now. A permitted permanent deletion can free stored-record space; an update does not consume another space.

Controlled independently

Select increases only for the activities you expect to use. Module-specific increases are available only when the related module is active.

All prices are in South African rand per prepaid month. Add-ons, seats and capacity may use an eligible shorter period or match the remaining base-plan period; they never extend beyond the base expiry. Nothing renews or charges automatically.
